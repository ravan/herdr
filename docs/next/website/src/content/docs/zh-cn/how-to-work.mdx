title: 使用 Herdr 的工作方式

---

在工作所在的地方运行 Herdr,从你所在的任何地方连接。

Herdr 由一个后台会话服务器和一个或多个终端客户端组成。窗格在服务器中持续运行。客户端负责连接、分离和渲染会话。

## 本地工作

在项目目录中启动 Herdr:

```bash
herdr
```

Herdr 会自动启动或连接到本地后台会话。你不需要管理 socket。在窗格里照常运行 shell、服务器、测试和智能体。

用 `ctrl+b q` 分离客户端。窗格会继续运行。

之后重新连接:

```bash
herdr
```

如果想结束会话并停止其中的窗格,停止服务器:

```bash
herdr server stop
```

## 通过普通 SSH 的远程工作

SSH 到有代码和凭据的机器,然后在那里运行 Herdr:

```bash
ssh you@server
herdr
```

这和终端复用器的用法一样。你的 shell 在远程,Herdr 服务器在远程,智能体和窗格都运行在远程机器上。用 `ctrl+b q` 分离并断开连接,之后再 SSH 回去,重新运行 `herdr`。

当你本来就工作在 SSH shell 里、在手机或平板的 SSH 客户端上,或者想要最简单的配置时,用这条路径。

## 用手机工作

你不需要 Herdr 手机应用或 Web 仪表盘。在手机上装任意一个 SSH 客户端,连到智能体所在的机器,在那里启动 Herdr:

```bash
ssh you@server
herdr
```

同一个持久的 Herdr 会话就会在手机终端中打开。TUI 会适应窄屏,所以你可以在不离开 SSH 的情况下检查智能体、切换工作区、查看窗格。

## 从本地终端远程工作

不先打开 shell,直接通过 SSH 连接:

```bash
herdr --remote workbox
herdr --remote ssh://you@server:2222
```

远程服务器保持窗格运行，并通过 SSH 发送终端内容和会话状态。本地 Herdr 使用本地主题和显示设置绘制 UI。

想让远程会话用起来像本地时,用这条路径。客户端运行在你的机器上,所以图像剪贴板粘贴等本地桌面功能可以桥接到远程服务器。如果你先 SSH 再在服务器上运行 `herdr`,Herdr 就完全运行在那台服务器上,无法读取你本地桌面的剪贴板。

对于经常连接的目标,把主机写进 SSH 配置:

```text
Host workbox
  HostName server.example.com
  User you
  Port 2222
```

然后这样连接:

```bash
herdr --remote workbox
```

## 该用哪条路径

本地工作用 `herdr`。想让 Herdr 在远程 shell 上表现得像 tmux,或者在用手机 SSH 客户端时,用 `ssh you@server` 再 `herdr`。需要通过本地 UI 操作一个远程会话并粘贴本地剪贴板图像时，使用 `herdr --remote <host>`。要在同一窗口使用 Local 和多台 SSH 机器，可通过 `herdr machine add <host> --label <label>` 保存目标；参见[连接机器](/zh-cn/docs/connecting-machines/)。

关于远程引导细节、命名远程会话、自定义二进制和直接终端附加,参见[持久化与远程访问](/zh-cn/docs/persistence-remote/)。

## 集合与 Hibernate

在菜单中选择 **new collection** 创建集合。右键点击工作区，选择 **Move family to collection...**，即可将它与受管理的工作树一起归入集合。

要暂时收起集合，右键点击集合标题并选择 **Hibernate collection**。集合会移到 **Hibernate** 下，新客户端默认折叠该分组。点击 Hibernate 展开，再右键点击其中的集合并选择 **Bring collection back**，即可将它放回普通列表。

收起集合会保留当前终端和输入目标。代理继续运行，通知仍会送达。明确跳转到已收起的代理时，会显示它的位置，但不会将集合移回普通列表。收起状态在服务器重启后仍然保留；展开状态属于各客户端的偏好设置。未提供 Hibernate 的服务器仍可使用现有集合和终端操作。

## 任务目标

打开菜单中的 **Missions…**，选择 **New mission…** 为目标命名。菜单会列出所有目标及其标签页数量，包括空目标。右键点击现有标签页，选择 **Add to mission…**，再选择目标。服务器确认分配后，标签页会显示 **◆** 标记和目标名称。

每个标签页只能显式分配给一个目标。选择另一个目标会替换分配，不会重新创建终端或改变焦点。重命名或调整标签页顺序会保留分配。关闭标签页会移除分配，但即使没有剩余标签页，目标也会保留。定义和有效分配在重启和实时交接后仍然保留。收起的集合中的标签页也可以分配目标。

JSON 调用者可以使用 `mission.create` 指定名称和可选的目标说明，使用 `mission.assign` 指定目标 ID 和类似 `{"kind":"tab","tab_id":"w1:t1"}` 的分配对象。请从 `tab.list` 获取当前公开标签页 ID。`tab.transfer` 必须包含 `tab_id`、目标 `workspace_id` 和 `insert_index`；它会移动整个标签页，并将分配更新为移动后的公开 ID。移动被拒绝时会保留原分配。`tab.move` 仍用于同一工作区内的排序。

窗格默认继承标签页的目标。右键点击代理行或终端窗格，选择 **Assign mission…**，即可单独分配该窗格。**Clear override** 会恢复菜单中说明的标签页目标。重新分配标签页不会覆盖窗格的显式分配。新拆分的窗格继承标签页目标；移动窗格会保留显式分配，没有显式分配时则继承目标标签页。代理重启不会改变所属关系。Shell 和编辑器也可分配目标，但不会显示为代理行。

点击代理区域的分组标签，可在 spaces、missions 和 priority 之间切换。按目标分组沿用现有代理名称和状态，也会显示已收起集合中的代理及其 **Hibernate** 标签。每一行仍可用于聚焦代理。分配其他端点的代理前，请先通过常规导航选择该端点；各端点目录保持独立。

JSON 调用者可用 `mission.assign_pane` 指定 `pane_id` 和 `mission_id`，用 `mission.clear_pane_override` 指定 `pane_id`。当前公开窗格 ID 可从 `pane.list` 获取。`organization.get` 在 `pane_mission_assignments` 中返回显式分配；有效所属关系在没有覆盖时继承标签页分配。两个方法分别公布支持情况，因此某项操作不可用时，集合、标签页目标和终端仍可正常使用。


不提供目标方法的服务器仍然保留现有集合和终端操作。

## Mission control

在菜单中选择 **Mission control**，或按 `ctrl+b m` 打开 **Spaces**。通过 `keys.mission_control` 可以使用与其他操作相同的语法配置快捷键。

概览显示当前选中的端点和会话。本地会话、已保存的 SSH 机器和直接 `--remote` 连接分别使用独立目录。已连接客户端共享服务器确认的成员关系和停放状态，各客户端分别保存展开状态。直接 SSH 连接按目标和会话恢复这些设置，与本地会话相互独立。每项服务器修改操作单独检查对应方法，因此即使服务器不支持创建或分配，仍可使用它支持的任务读取或重命名操作。收到已确认的目录后，即使没有公布读取方法，也可以打开定义菜单。窄终端会用省略号缩短过长的端点或会话名称，同时保留目标行和公开 ID。加宽终端可以查看完整会话名称。

重新连接后，Herdr 会重新获取完整目录。搜索条件和仍存在目标的选择显示会保留。重新连接前捕获的操作需要明确重新选择当前行；服务器重启或成员关系被移除时，旧操作不会转向重用的 ID。组织管理和任务内工作树创建失败后的本地通知会保留至明确关闭，终端输入和重新连接不会清除它们。

在 **Missions** 中选择任务标题或成员，点击 **new worktree** 或按 `ctrl+n`。从标题进入时，需要选择已打开的仓库父工作区；关联工作树成员使用现有家族的父工作区。在现有 **new worktree** 表单中点击 **mission**，或按 Tab，选择任务或 **None**。取消选择保留已输入的分支名称。检出目录继承家族的集合，并在报告成功之前将初始标签页分配给所选任务。在该标签页中按正常方式启动代理。旧服务器禁用任务创建操作，普通工作树创建仍可使用。如果 Git 创建成功后任务被删除或终端创建失败，错误会显示保留的检出目录路径。

点击 **Spaces**、**Missions** 或 **Needs you**，也可以使用 Tab 和 Shift+Tab 切换视图。**Missions** 显示空任务、明确分配的标签页及其有效窗格成员。窗格的覆盖分配优先于标签页的任务，每个窗格只显示一次。行中包含实际位置、成员来源、公开 ID 和 **Hibernate** 标记。右键点击已有标签页或窗格行可以打开现有任务分配对话框。各分配操作分别检查服务器能力，只在确认后更新。

**Needs you** 显示 Herdr 当前报告为 blocked 的代理，包括已停放集合中的代理。选择行会跳转到原有终端，在那里回复。Herdr 观察到状态变化后，该行离开队列。如果已选成员离开任务，或代理不再 blocked，Enter 会显示通知，直到你明确选择当前行。编辑搜索或切换视图不会把过时操作转向其他目标。

搜索工作区和标签页名称、分支、实际位置、集合名称、任务分配，以及窗格或代理的可用标签。搜索包含已停放的目标，并用 **Hibernate** 标记，即使其集合或家族已折叠。点击集合、家族或 Hibernate 标题可以展开或折叠此概览。展开状态由客户端保存。

使用方向键或 Page Up/Page Down 选择，按 Enter 或点击行跳转，用滚轮或滚动条滚动列表。窄终端使用紧凑的行。每个结果对应已有工作区、标签页或窗格。跳转到停放的位置不会恢复集合。目标已关闭或无法连接时，客户端会保留通知，不会转向另一个同名目标。

概览打开时，搜索文本、粘贴、键盘和鼠标输入都由概览处理。按 Escape 或点击 **esc close** 取消，保留原有窗格焦点、回滚位置、缩放、布局和运行中的任务。各端点的目录保持独立。

## 维护集合和任务

右键点击集合标题，可以选择 **Rename collection**、**Move earlier**、**Move later** 或 **Delete collection**。排序包含已休眠的集合。删除需要确认：工作区保持打开，家族回到 **Uncollected**。要移除单个家族，右键点击工作区，依次选择 **Move family to collection...** 和 **Remove from collection (Uncollected)**。

在菜单中选择 **Missions**，通过名称和 ID 选择任务，可以使用 **Rename mission**、**Edit objective**、**Move earlier**、**Move later** 和 **Delete mission**。清空目标输入会移除目标。确认删除会清除该任务的标签页和窗格分配，终端和代理继续运行。名称和顺序变化不会改变 ID、成员关系或终端焦点。

右键点击标签页并选择 **Remove tab from mission**，可以清除标签页分配。窗格菜单中的 **Clear override** 恢复继承标签页任务，因此窗格可能仍属于同一任务。**Remove inherited tab membership** 需要确认，会移除所有继承该标签页分配的窗格；明确设置的窗格覆盖分配保留。系统没有单个窗格退出继承任务的独立设置。

空集合和空任务继续保存。概览中的空行说明如何添加现有成员。定义菜单中的 **Membership and restore** 说明公开 ID 成员关系，以及恢复时移除不可用目标的行为。系统不会为过期引用创建替代终端。重新打开受管理的仓库家族会恢复集合，关闭独立工作区会移除其家族引用。过期、已删除、已重新分配或不支持的操作显示持续的本地通知，其他终端操作继续可用。
